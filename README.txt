MAGBURUGTO PRINT AND INKS — ANDROID PWA V3

Designed for Android phones and tablets.

HOW TO INSTALL:
1. Put these files on a web host that supports HTTPS (GitHub Pages, Netlify, etc.).
2. Open the HTTPS site in Chrome on Android.
3. Tap Install when the app shows the Install button, or Chrome menu > Add to Home screen.
4. The app can then open like a normal standalone app.

IMPORTANT:
PWA installation requires an HTTPS website (localhost is an exception). This package is not a compiled APK.
Data is stored locally on the device/browser. Use Backup Data regularly.
